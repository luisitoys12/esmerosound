Guía Completa de Esmerosound

¡Bienvenido a la guía definitiva de Esmerosound! Este documento te ayudará a entender cómo usar, instalar, desplegar y personalizar tu propia instancia del sitio web.

Guía de Usuario

Esta sección está dedicada a los usuarios finales del sitio web: oyentes y administradores de contenido.

Para Oyentes

Funcionalidades Principales

  • Reproductor en Vivo: El reproductor principal te permite escuchar la transmisión en vivo. Puedes controlar el volumen, ver la canción actual y acceder al historial reciente.
  • Programación: En la sección "Programación", puedes ver el horario de todos nuestros shows para cada día de la semana.
  • Podcasts: ¿Te perdiste un programa? Encuéntralo en la sección de "Podcasts" y escúchalo cuando quieras.
  • Equipo: Conoce a nuestros locutores en la sección "Equipo". Haz clic en un miembro para ver su perfil detallado, biografía y redes sociales.
  • Top 10: Descubre las canciones más populares de la semana y mira sus videoclips.
  • Solicitudes: ¿Quieres escuchar una canción? Ve a "Solicitudes" y pídenosla.

Para Administradores

El panel de administración te da control total sobre el contenido del sitio web. Para acceder, inicia sesión con tus credenciales en la página /login.

Gestión de Contenido

  • Dashboard: Tu centro de operaciones. Desde aquí puedes navegar a todas las secciones de gestión.
  • Generador IA de Shows: Una herramienta para crear descripciones de programas atractivas usando inteligencia artificial.
  • Gestionar Noticias: Añade, edita y elimina artículos de noticias.
  • Gestionar Slideshow: Controla el carrusel de la página de inicio.
  • Gestionar Equipo: Añade nuevos miembros al equipo y edita sus perfiles.
  • Ajustes de Streaming: Configura la fuente de tu transmisión.
  • Ajustes Web: Cambia el título, la descripción y las URLs de redes sociales del sitio web.

Guía de Instalación y Despliegue

Esta sección es para desarrolladores que deseen instalar y desplegar su propia versión de Esmerosound.

1. Requisitos Previos

  • Node.js: Versión 20.x o superior.
  • Git: Para clonar el repositorio.
  • Cuenta de Firebase: Necesitarás un proyecto de Firebase para la base de datos y la autenticación.
  • Docker (Opcional): Si deseas usar Docker Compose para el desarrollo local.

2. Configuración de Firebase

Este proyecto utiliza Firebase para la gestión de contenido. Sigue estos pasos:

  1. Ve a la Consola de Firebase y crea un nuevo proyecto.
  2. Dentro de tu proyecto, ve a Authentication y habilita el proveedor de Email/Contraseña y Google.
  3. Ve a Firestore Database y crea una base de datos en modo de producción.
  4. Ve a la configuración del proyecto (icono de engranaje) y, en la sección "Tus apps", crea una nueva aplicación web.
  5. Copia las credenciales de configuración de Firebase (el objeto firebaseConfig).

¡Importante! Crea un archivo .env.local en la raíz de tu proyecto para las credenciales.

NEXT_PUBLIC_FIREBASE_API_KEY="TU_API_KEY"
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN="TU_AUTH_DOMAIN"
NEXT_PUBLIC_FIREBASE_PROJECT_ID="TU_PROJECT_ID"
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET="TU_STORAGE_BUCKET"
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID="TU_SENDER_ID"
NEXT_PUBLIC_FIREBASE_APP_ID="TU_APP_ID"

3. Instalación Local

# 1. Clona el repositorio
git clone https://github.com/tu-usuario/esmerosound.git
cd esmerosound

# 2. Crea el archivo .env.local (ver paso anterior)

# 3. Crea el archivo .npmrc con el siguiente contenido:
legacy-peer-deps=true

# 4. Instala las dependencias
npm install

# 5. Inicia el servidor de desarrollo
npm run dev

La aplicación estará disponible en http://localhost:9002.

4. Despliegue

Vercel (Recomendado)

Vercel es la plataforma ideal para desplegar aplicaciones Next.js.

  1. Haz un fork de este repositorio en tu cuenta de GitHub.
  2. Ve a Vercel e inicia sesión con tu cuenta de GitHub.
  3. Crea un nuevo proyecto e importa tu repositorio.
  4. Vercel detectará automáticamente que es un proyecto Next.js.
  5. Ve a la configuración del proyecto en Vercel (Settings -> Environment Variables) y añade las mismas variables de tu archivo .env.local.
  6. ¡Listo! Vercel desplegará tu sitio automáticamente.

Netlify

El proceso es muy similar al de Vercel.

  1. Conecta tu repositorio de GitHub a Netlify.
  2. Añade tus variables de entorno de Firebase en la configuración del sitio (Site settings -> Build & deploy -> Environment).
  3. Despliega el sitio.

Docker Compose (Linux)

Si prefieres usar Docker, el repositorio incluye un Dockerfile y un docker-compose.yml.

  1. Asegúrate de tener Docker y Docker Compose instalados.
  2. Crea tu archivo .env.local como se describe arriba.
  3. Ejecuta el siguiente comando para construir y levantar el contenedor:
docker-compose up -d --build

La aplicación estará disponible en http://localhost:9002.

Nota sobre GitHub Pages: Aunque el repositorio incluye un workflow para GitHub Pages, no es la plataforma recomendada. Este sitio utiliza funciones de servidor de Next.js para cargar contenido dinámico, las cuales no funcionan en un entorno estático como GitHub Pages. Para una experiencia completa, utiliza Vercel, Netlify o un despliegue con Docker.

5. Personalización

  • Contenido: La mayor parte del contenido (noticias, equipo, slideshow, ajustes) se gestiona desde el panel de administración en /login.
  • Estilos: Los colores y la apariencia se controlan en src/app/globals.css. Modifica las variables CSS para cambiar el tema.
  • Programación: El horario de los programas se gestiona directamente en el archivo src/lib/schedule-data.ts.
