Guía de Despliegue y Uso: Esmerosound

Bienvenido a la guía completa de Esmerosound. Este documento te ayudará a instalar, desplegar y personalizar tu propia instancia del sitio web.

1. Requisitos Previos

Antes de empezar, asegúrate de tener instalado lo siguiente:

  • Node.js: Versión 20.x o superior.
  • Git: Para clonar el repositorio.
  • Cuenta de Firebase: Necesitarás un proyecto de Firebase para la base de datos y la autenticación.

2. Configuración de Firebase

Este proyecto utiliza Firebase para la gestión de contenido dinámico. Sigue estos pasos:

  1. Ve a la Consola de Firebase y crea un nuevo proyecto.
  2. Dentro de tu proyecto, ve a Authentication y habilita el proveedor de Email/Contraseña y Google.
  3. Ve a Firestore Database y crea una base de datos en modo de producción.
  4. Ve a la configuración del proyecto (icono de engranaje) y, en la sección "Tus apps", crea una nueva aplicación web.
  5. Copia las credenciales de configuración de Firebase (el objeto `firebaseConfig`).

¡Importante! Necesitas crear un archivo .env.local en la raíz de tu proyecto para las credenciales. Estas variables son necesarias tanto para el desarrollo local como para el despliegue.

Archivo .env.local

Crea el archivo .env.local en la raíz del proyecto y añade tus credenciales de Firebase así:

NEXT_PUBLIC_FIREBASE_API_KEY="TU_API_KEY"
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN="TU_AUTH_DOMAIN"
NEXT_PUBLIC_FIREBASE_PROJECT_ID="TU_PROJECT_ID"
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET="TU_STORAGE_BUCKET"
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID="TU_SENDER_ID"
NEXT_PUBLIC_FIREBASE_APP_ID="TU_APP_ID"

3. Instalación Local

Para ejecutar el proyecto en tu máquina local:

# 1. Clona el repositorio
git clone https://github.com/tu-usuario/esmerosound.git
cd esmerosound

# 2. Crea el archivo .env.local con tus credenciales de Firebase

# 3. Instala las dependencias
npm install

# 4. Inicia el servidor de desarrollo
npm run dev

La aplicación estará disponible en http://localhost:9002.

4. Despliegue

Este proyecto está optimizado para ser desplegado en varias plataformas modernas.

Vercel (Recomendado)

Vercel es la plataforma ideal para desplegar aplicaciones Next.js.

  1. Haz un fork de este repositorio en tu cuenta de GitHub.
  2. Ve a Vercel e inicia sesión con tu cuenta de GitHub.
  3. Crea un nuevo proyecto e importa tu repositorio.
  4. Vercel detectará automáticamente que es un proyecto Next.js.
  5. Ve a la configuración del proyecto en Vercel (Settings -> Environment Variables) y añade las mismas variables de tu archivo .env.local.
  6. ¡Listo! Vercel desplegará tu sitio y se actualizará automáticamente con cada `push` a la rama `main`.

Netlify

El proceso es muy similar al de Vercel.

  1. Conecta tu repositorio de GitHub a Netlify.
  2. Netlify debería detectar la configuración de Next.js.
  3. Añade tus variables de entorno de Firebase en la configuración del sitio (Site settings -> Build & deploy -> Environment).
  4. Despliega el sitio.

Docker Compose

Si prefieres usar Docker, el repositorio incluye un Dockerfile y un docker-compose.yml.

  1. Asegúrate de tener Docker y Docker Compose instalados.
  2. Crea tu archivo .env.local como se describe arriba.
  3. Ejecuta el siguiente comando para construir y levantar el contenedor:
docker-compose up -d --build

La aplicación estará disponible en http://localhost:9002.

5. Personalización

La mayor parte del contenido del sitio se gestiona desde el panel de administración.

  • Admin Panel: Inicia sesión en /login para acceder al dashboard. Desde aquí puedes gestionar noticias, el equipo, el slideshow y los ajustes generales del sitio web.
  • Estilos: Los colores y la apariencia se controlan con variables CSS de Tailwind. Puedes modificar los valores HSL en src/app/globals.css para cambiar el tema.
  • Programación de Shows: Por ahora, el horario de los programas se gestiona directamente en el archivo src/lib/schedule-data.ts. Puedes editar este archivo para reflejar tu programación.
