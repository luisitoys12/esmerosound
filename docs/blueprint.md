# **App Name**: Esmeralda Digital

## Core Features:

- Programming Schedule: Display a programming schedule with interactive buttons for each day of the week.
- Live Streaming with Metadata: Stream audio with live metadata display (song title, artist, etc.).
- News Section: Display news feed related to Esmeralda Sound.
- AI-Powered Show Descriptions: AI tool to automatically generate show descriptions based on music library and programming schedule.
- Firebase Auth: User authentication system with Firebase Auth.
- Streaming Source Selection: Configuration to allow for streaming from Azuracast, Zenofm, or Live365.

## Style Guidelines:

- Primary color: Strong blue (#2962FF) to communicate reliability and technological savvy.
- Background color: Light gray (#F0F2F5), close in hue to the primary but very desaturated, for a light color scheme.
- Accent color: Violet (#7838F0), analogous to blue but a clearly distinct contrast color for highlighting key interactive elements.
- Body and headline font: 'Inter', a grotesque sans-serif for a modern, neutral look.
- Clean, modern layout with easy navigation.
- Use modern and simple icons for navigation and features.
- Subtle transitions and animations for a smooth user experience.
